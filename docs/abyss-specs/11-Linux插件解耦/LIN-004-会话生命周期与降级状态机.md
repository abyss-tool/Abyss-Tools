## 1. 目标与范围

定义从 `openSession` 到 `CLOSED` 的完整生命周期、进程/PTY/VNC 治理、引用计数、失败与降级语义、断电重启自检。

## 2. 生命周期

| 阶段 | 触发 | 动作 | 对外状态 |
| --- | --- | --- | --- |
| 创建 | `openSession(spec, grant)` | 校验 grant、分配 sessionId、canonical 断言工作区、写账本 | UNINITIALIZED |
| 资产 | 检查 `rootfsId/imageId` | 缺失 → 下载 / 校验 / 原子安装 | ASSET_CHECKING / ASSET_DOWNLOADING |
| 探测 | 资产 READY | ptrace / memlock / arch / 存储 / libc 探测 | PROBING |
| 就绪 | 探测通过 | 拉起引擎、挂载工作区、注册回调 | READY |
| 占用 | `exec/pty` | 置 BUSY，串行执行，阶段进度上报 | BUSY → READY |
| 降级 | 平台限制 | DEGRADED，展示原因与切域选项 | DEGRADED |
| 不可用 | 无法恢复 | UNAVAILABLE + 已知 ROM 清单 | UNAVAILABLE |
| 关闭 | `close()` / 引用归零 / 宿主死亡 | 终止子进程、回收 PTY/VNC、清理工作区、撤销 grant | CLOSING → CLOSED |

## 3. 进程治理

| 对象 | 托管方式 | 退出条件 | 清理 |
| --- | --- | --- | --- |
| PRoot 进程树 | 前台服务 + 进程组；记录 pid/pgid | close / 超时 / 被系统杀 | `kill(-pgid)` + 等待回收，禁止留孤儿 |
| QEMU 子进程 | 同上；额外记录 VNC 端口与 qcow2 句柄 | 同上 | 关闭监听、刷新磁盘、释放文件锁 |
| exec 命令 | 会话内串行，单条 `execTimeoutSec` | 完成 / 超时 / 取消 | 终止进程树，保留已产生日志 |
| PTY | 主/从设备 + 进程组 + `TIOCSWINSZ` 同步 | close / Ctrl-D / 窗口关闭 | 关闭 fd、回收从设备 |
| 前台服务 | 会话引用计数 > 0 时常驻 | 引用归零后延迟 60s 停止 | 停止前完成清理 |

**超时与流防护（沿用 SHL-003）**
- stdout / stderr 并发读取，禁止串行等待造成死锁；
- 单流 1MB 上限，超限置 `truncated` 并停止读取，UI 必须如实标注；
- 30s 真超时看门狗用于探测/短命令；长构建用会话级 `execTimeoutSec`（默认 1800s）；
- `exitCode == 0` 才算成功，`failureSummary()` 为统一错误摘要出口（SHL-001）。

## 4. 引用计数与资源回收

```
refCount = 持有 ILinuxSession 的消费方数量（宿主代理 + 构建器）
  · openSession 成功 → +1
  · 消费方 Binder 死亡 → -1，触发 DeathRecipient
  · close() → -1
  · refCount == 0 → 启动 60s 延迟回收（防短暂重建抖动）
  · 延迟内重新 open 同域 → 复用会话环境，仍新建 sessionId
  · 延迟到 → CLOSING：终止进程、清工作区、撤销 grant、写审计
```

| 资源 | 回收时机 |
| --- | --- |
| 会话工作区 `/workspace/build-<ts>` | close 后清理；失败切换路径不清理 |
| pip / Maven 缓存 | 跨会话保留，只读优先共享 |
| 已校验资产 | 保留（受配额 LRU 管理） |
| VNC 随机口令 / 端口 | 会话关闭即失效 |
| SessionGrant | 会话关闭 + 宿主撤销，双保险 |

## 5. 降级状态机（与 LIN-005 联动）

```
PROBING
 ├─ ptrace 可用（App 沙箱）           → READY[via=app_sandbox]
 ├─ ptrace 受限 + Shizuku 已授权       → READY[via=uid2000]
 ├─ ptrace 受限 + Shizuku 未授权       → DEGRADED[reason=NEED_SHIZUKU] → 引导授权 → 重探测（最多 1 次）
 ├─ ptrace 受限 + Shizuku 授权后仍失败 → DEGRADED[reason=PLATFORM_BLOCKED]
 │      ├─ allowDomainFallback=true  → 用户确认 → CLOSED → openSession(QEMU_VM)
 │      └─ 否 / 无镜像 / 存储不足     → UNAVAILABLE
 └─ QEMU 探测不满足（内存/memlock）    → UNAVAILABLE[reason=E_VM_RESOURCE] + 降档建议
```

| 纪律 | 说明 |
| --- | --- |
| 不允许静默重试 | 同一原因最多重探测 1 次，且必须用户可见 |
| 不允许静默切域 | 切域必须弹层确认并展示耗时 / 存储 / 性能预期 |
| 不允许假装 READY | 资产 / 探测 / 授权任一未绿，`getState()` 不得返回 READY |
| 平台限制如实上报 | ColorOS 15/16、MagicOS 列入 `romHint`，附带可执行建议 |

## 6. 功能需求

| 编号 | 需求描述 |
| --- | --- |
| FR-001 | 会话 id 全局唯一且可审计；日志以 sessionId 为主键。 |
| FR-002 | 所有子进程属同一进程组，close 必须整组终止，不得留孤儿。 |
| FR-003 | 引用计数归零后延迟 60s 回收；前台服务在无会话时自行停止。 |
| FR-004 | 状态变化经 `ILinuxSessionCallback` 推送，UI 统一 `UiState` 三态。 |
| FR-005 | exec 退出码 / 信号 / truncated 如实回传，不吞异常（N-TERM-002 FR-005）。 |
| FR-006 | PTY 支持 Ctrl-C / Ctrl-D / Tab 透传与窗口大小同步。 |
| FR-007 | 断电 / 进程被杀后重启：启动自检清理残留工作区、临时资产与孤儿进程记录。 |
| FR-008 | 插件崩溃不得导致宿主重启；宿主重启后所有旧 grant 与会话失效。 |
| FR-009 | 失败切换构建路径复用同一 sessionId，不清理工作区产物。 |
| FR-010 | 工作区 canonical 路径断言在 App 私有目录内，穿越即拒。 |

## 7. 失败语义与边界

- `E_SESSION_CLOSED` / `E_GRANT_EXPIRED` / `E_CONCURRENT_LIMIT` 等必须转为人话提示，错误码只进日志。
- 平台限制属 `UNAVAILABLE`，不得包装成代码缺陷或进入重试循环。
- 超时终止后已产生的部分产物保留并标注「未完成」，便于诊断而非静默清除。
- 审计日志不记命令正文与项目内容（SEC-009 数据最小化）。
