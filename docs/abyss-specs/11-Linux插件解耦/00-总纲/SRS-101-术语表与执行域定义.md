## 1. 目标与范围

统一「Linux 插件」语境下的名词，尤其是**执行域**、**底座**、**资产**、**会话**、**能力**五个最容易混淆的概念，避免把「内置 Linux」误解为「刷内核」或「root」。

## 2. 术语表

| 术语 | 英文 / 标识 | 定义 | 反例（禁止混用） |
| --- | --- | --- | --- |
| Linux 插件 | `abyss-plugin-linux` | 独立 APK，唯一持有 rootfs、镜像、PRoot/QEMU 引擎、会话与 Shizuku 授权的引擎级插件 | 不是主壳 feature，不是一个 Linux 内核模块 |
| 执行域 | `RuntimeDomain` | Linux 运行环境的一种实现形态，枚举 `PROOT_USERLAND` / `QEMU_VM` | 不是「插件」，不是「构建路径」 |
| 用户态执行域 | `PROOT_USERLAND` | PRoot 经 `ptrace` 在用户态模拟 chroot，运行 Alpine 用户空间，**复用 Android 内核**，无独立内核、免 Root、约 4MB 底座 | 不等于「完整 Linux 系统」，不等于 Termux |
| 完整系统执行域 | `QEMU_VM` | QEMU TCG 用户态仿真，运行自带 Linux 内核的整机镜像，含 VNC 显示、快照、独立网络栈 | 不等于 KVM，不等于「有 root 的宿主机」 |
| 底座 | `runtime base` | 让某个执行域跑起来的最小自包含物：PRoot 引擎 + Alpine rootfs 管理逻辑（AAR / 原生库） | 不包含工具链（JDK/Gradle/aapt2），也不包含 VM 镜像 |
| rootfs | `rootfs` | Alpine 根文件系统压缩包（tar.gz / 分卷），供 PROOT_USERLAND 解包到 App 私有目录 | 不是 qcow2，不是系统镜像 |
| 镜像 | `image` | QEMU_VM 用的整盘镜像（qcow2/raw），含内核、init、用户空间 | 不是 rootfs，不是构建产物 APK |
| 工具链 | `toolchain` | 应用层构建工具集：Anpyra / ARM64 aapt2+固定壳 DEX / JDK+Android SDK+Gradle | 不属于底座，由构建器按需请求安装到会话工作区 |
| 资产 | `asset` | 需下载校验的大二进制：rootfs、VM 镜像、引擎原生库、可选工具链包；走 `abyss-asset-v1` | 不是 `abyss-patch-v1` 的载荷 |
| 会话 | `RuntimeSession` | 一次有生命周期的 Linux 运行实例（含域、rootfs/镜像 id、挂载、环境、限额、状态） | 不是「一次构建」，一个会话可承载多次 exec |
| 会话句柄 | `SessionHandle` | 跨插件暴露给消费方的受限 AIDL 代理，只能 exec / pty / 传文件 / close | 不是 Binder 全权，不是 Shizuku 句柄 |
| 能力 | `capability` | 插件对外声明的、可被依赖的稳定接口标识，本设计为 `linux-runtime-v1` | 不是权限，不是分类 |
| 依赖 | `depends` | plugin.json v2 中消费者声明的「能力 + 插件 id + 最低版本」三元组 | 不是 Gradle 依赖，不是隐式调用 |
| 中介 | `PluginBroker` | 宿主 `core:plugin` 新增组件：依赖解析、同签名校验、能力绑定、令牌签发、死亡回收 | 不是插件，不执行 Linux 命令 |
| 授权令牌 | `SessionGrant` | 宿主签发的短期凭据（调用方包名 + 签名指纹 + capability + nonce + expiry） | 不是 Shizuku 授权，不能跨会话复用 |
| 宿主 | `Abyss-Tools` | 主壳 APK，提供插件框架、索引、安装、更新与中介 | 不承载 Linux 引擎 |
| 构建路径 | `BuildPath` | 应用构建器三选一：Anpyra / aapt2+固定壳 / 标准 Gradle | 与执行域正交：同路径可在不同域运行 |
| 工作区 | `workspace` | 会话内隔离目录 `/workspace/build-<timestamp>`，存放导入项目与中间产物 | 不是 App 私有目录根，不允许路径穿越 |

## 3. 执行域能力矩阵

| 能力 | `PROOT_USERLAND` | `QEMU_VM` | 说明 |
| --- | --- | --- | --- |
| 独立 Linux 内核 | ✗（复用 Android 内核） | ✓ | 「整个 Linux」字面由 QEMU_VM 满足 |
| 免 Root | ✓ | ✓ | 两者均不需要 su |
| 依赖 `ptrace` | ✓ | ✗ | ColorOS / MagicOS 可能拦截 |
| 依赖 Shizuku（推荐 / 可用） | 推荐 | 推荐 | 绕普通 App 沙箱限制 / RLIMIT_MEMLOCK |
| 冷启动量级 | 秒级（目标 ≤8s） | 分钟级（目标 ≤180s） | 见 ENG-100 §7 |
| 内存量级 | 低（JVM 堆 ≤2048m） | 高（VM 建议 ≥1.5GB 空闲） | — |
| 冷镜像体积 | rootfs 约 30–120MB | 0.5–4GB | 分卷下载 |
| 交互式 PTY | ✓ | ✓（经 VNC / 串口） | 统一 `pty()` 接口 |
| 图形显示 | ✗ | ✓（VNC） | — |
| 快照 / 挂起恢复 | ✗ | ✓ | — |
| 端口转发 / iptables | 受限 | ✓ | VM 域才适合网络类实验 |
| 构建适用性 | 三路径默认 | 路径三兜底 / 特殊依赖 | TCG 慢，不作默认 |
| 执行域切换 | 需关闭会话重建 | 需关闭会话重建 | 会话不可原地换域 |

## 4. 契约与接口（枚举定义）

```kotlin
enum class RuntimeDomain { PROOT_USERLAND, QEMU_VM }

enum class SessionState {
    UNINITIALIZED, ASSET_CHECKING, ASSET_DOWNLOADING, PROBING,
    READY, DEGRADED, BUSY, UNAVAILABLE, CLOSING, CLOSED
}

data class CapabilityId(val value: String)   // 固定 "linux-runtime-v1"
```

命名纪律：
- 域、状态、能力标识为**契约常量**，禁止在业务代码里散落字符串字面量（沿用 `ARC-010` FR-002 / `ToolDef.id` 纪律）。
- `linux-runtime-v1` 的 `v1` 是能力版本，与 `HOST_API_VERSION`、`plugin.version` 三者互不混用。
- 「内置 Linux」在对外文案中一律写成「Linux 插件提供用户态/完整系统两种执行域」，禁止写成「刷入 Linux」或「获得 root」。

## 5. 失败语义与边界

- 执行域不可用必须给出域级原因码（见 DC-102 错误码表），禁止笼统报「启动失败」。
- 不得把 `PROOT_USERLAND` 描述为「完整 Linux 系统」；不得把 `QEMU_VM` 描述为「免配置高性能」。
- 任一术语在子规格中出现歧义，以本文件为准并回填修订。
