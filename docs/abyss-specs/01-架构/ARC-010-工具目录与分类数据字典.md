## 1. 目标与范围

ToolCatalog 定义 12 个 ToolCategory、约 30 个 ToolDef（id/title/summary/category/status/pluginId/iconKey），是导航页与仪表盘统计的数据底座。

## 2. 现状锚点（克隆研究实测）

- `Abyss-Tools/core/common/src/main/kotlin/com/abyss/tools/core/common/ToolCatalog.kt`
- `Abyss-Tools/feature/navhub/src/main/kotlin/com/abyss/tools/feature/navhub/NavHubScreen.kt`

> 研究口径：2026-11-21 对 `github.com/abyss-tool` 组织下 19 个公开仓库（主仓 / 发布仓 / 插件中心 / 13 归档插件仓 / 3 引擎级插件仓）全量拉取，共 511 个文件；主仓 296 个文件、约 22 个 feature 模块。

## 3. 功能需求

| 编号 | 需求描述（原子、可验证） |
|---|---|
| FR-001 | 插件分类 PLUGINS 必须排在 categories 首位。 |
| FR-002 | ToolDef.id 全局唯一且稳定（AbyssRoot 路由消费常量，禁止散落字符串）。 |
| FR-003 | status == PLUGIN 时 pluginId 必填且可解析。 |
| FR-004 | pluginDrivenCount / builtInCount 供仪表盘统计，随目录自动计算。 |
| FR-005 | toolsOf(category) / byId(id) 为唯二查询入口。 |

> 纪律：每条 FR 必须至少被一条 AC 或一个自动化用例覆盖；下表 AC 为关键验收条件，完整覆盖关系由 `QA-008 需求追溯矩阵` 与 spec-lint 登记校验。需求变更需同步更新本文件与对应的测试夹具（`src/test/resources` 为通道契约镜像）。

## 4. 契约与接口

```kotlin
data class ToolDef(val id: String, val title: String, val summary: String,
    val category: ToolCategory, val status: ToolStatus,
    val pluginId: String? = null, val iconKey: String)
```
12 分类：plugins / system / terminal / dev / sandbox / disguise / media / automation / desktop / network / data。

## 5. 失败语义与边界

- 坏数据 / 非法版本 / 路径穿越 / 签名不符一律 fail-closed 拒绝并给人话错误，不猜测、不静默降级。
- 远端数据统一走 `UiState`（Loading / Error / Data），加载中禁止展示假数据。
