## 1. 目标与范围

Backdrop（有采样源 + API 31+，blur + AGSL lens + 霜面 + 边缘受光 + 内阴影）与 Frosted（无源 / API<31，零 GPU 管线诚实降级）双档。

## 2. 现状锚点（克隆研究实测）

- `Abyss-Tools/core/designsystem/src/main/kotlin/com/abyss/tools/core/designsystem/glass/Glass.kt`
- `Abyss-Tools/vendor/backdrop/src/main/java/com/kyant/backdrop/DrawBackdropModifier.kt`
- `Abyss-Tools/core/common/src/main/kotlin/com/abyss/tools/core/common/GlassProbe.kt`

> 研究口径：2026-11-21 对 `github.com/abyss-tool` 组织下 19 个公开仓库（主仓 / 发布仓 / 插件中心 / 13 归档插件仓 / 3 引擎级插件仓）全量拉取，共 511 个文件；主仓 296 个文件、约 22 个 feature 模块。

## 3. 功能需求

| 编号 | 需求描述（原子、可验证） |
|---|---|
| FR-001 | drawBackdrop 的全部 lambda 必须记忆化（ModifierNodeElement 按身份比较，重组期新建 lambda 会引发 draw 失效风暴）。 |
| FR-002 | 效果级 runCatching 单项降级，进程存活优先于视觉效果。 |
| FR-003 | OEM RenderEffect / AGSL 差异导致失败时自动降级到 Frosted，不崩溃。 |
| FR-004 | 业务 UI 禁止直接调用 vendor:backdrop API。 |

> 纪律：每条 FR 必须至少被一条 AC 或一个自动化用例覆盖；下表 AC 为关键验收条件，完整覆盖关系由 `QA-008 需求追溯矩阵` 与 spec-lint 登记校验。需求变更需同步更新本文件与对应的测试夹具（`src/test/resources` 为通道契约镜像）。

## 4. 契约与接口

| 档位 | 条件 | 渲染 |
| --- | --- | --- |
| Backdrop | 有采样源 + API 31+ | blur +（API 33+）AGSL lens 折射/色散 + 霜面 tint + 边缘受光 + 内阴影 |
| Frosted | 无源 或 API < 31 | 霜面渐变 + 边缘光（零 GPU 管线） |

## 5. 失败语义与边界

- 坏数据 / 非法版本 / 路径穿越 / 签名不符一律 fail-closed 拒绝并给人话错误，不猜测、不静默降级。
- 远端数据统一走 `UiState`（Loading / Error / Data），加载中禁止展示假数据。
