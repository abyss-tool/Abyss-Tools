## 1. 目标与范围

框架期不引 navigation-compose；AbyssBackStack 自维护 mutableStateOf(List<Screen>)，Crossfade 切页，BackHandler 手势返回。

## 3. 功能需求

| 编号 | 需求描述（原子、可验证） |
|---|---|
| FR-001 | 底栏仅顶层 tab 显示（stack.size == 1），详情页沉浸全屏。 |
| FR-002 | 返回栈可序列化（rememberSaveable + listSaver），旋转 / 深浅色切换 / 进程重建后原位恢复。 |
| FR-003 | AppManagerDetail 只序列化包名键，恢复后经 AppInfoProvider 异步重挂；查不到诚实留在列表页。 |
| FR-004 | 玻璃采样源在内容根上，任何页面滚过玻璃件下方都被真实采样。 |
| FR-005 | 新增页面必须同时登记 Screen 类型、路由分支与返回栈序列化策略。 |

> 纪律：每条 FR 必须至少被一条 AC 或一个自动化用例覆盖；下表 AC 为关键验收条件，完整覆盖关系由 `QA-008 需求追溯矩阵` 与 spec-lint 登记校验。需求变更需同步更新本文件与对应的测试夹具（`src/test/resources` 为通道契约镜像）。

## 5. 失败语义与边界

- 坏数据 / 非法版本 / 路径穿越 / 签名不符一律 fail-closed 拒绝并给人话错误，不猜测、不静默降级。
- 远端数据统一走 `UiState`（Loading / Error / Data），加载中禁止展示假数据。
