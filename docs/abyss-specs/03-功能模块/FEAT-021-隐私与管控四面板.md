## 1. 目标与范围

v0.9.0 第四域：权限审计批量回收 / 敏感操作记录（appops query-op）/ Doze 白名单 / netpolicy 流量策略。

## 2. 现状锚点（克隆研究实测）

- `Abyss-Tools/feature/syspower/src/main/kotlin/com/abyss/tools/feature/syspower/PrivacyPanels.kt`

> 研究口径：2026-11-21 对 `github.com/abyss-tool` 组织下 19 个公开仓库（主仓 / 发布仓 / 插件中心 / 13 归档插件仓 / 3 引擎级插件仓）全量拉取，共 511 个文件；主仓 296 个文件、约 22 个 feature 模块。

## 3. 功能需求

| 编号 | 需求描述（原子、可验证） |
|---|---|
| FR-001 | 权限审计：dumpsys package 解析 → 危险权限白名单交集 → 逐项 pm grant/revoke + 批量 executeAll。 |
| FR-002 | 半程失败如实报错，不伪装成功；顺序执行需可中断。 |
| FR-003 | 敏感操作记录覆盖相机 / 麦克风 / 定位 / 剪贴板四类 op。 |
| FR-004 | Doze 白名单系统内置条目拒绝时透传原始错误。 |
| FR-005 | 流量策略按 uid 拒绝/解除后台流量，uid 经 PackageManager 解析。 |

> 纪律：每条 FR 必须至少被一条 AC 或一个自动化用例覆盖；下表 AC 为关键验收条件，完整覆盖关系由 `QA-008 需求追溯矩阵` 与 spec-lint 登记校验。需求变更需同步更新本文件与对应的测试夹具（`src/test/resources` 为通道契约镜像）。

## 4. 契约与接口

沿用宿主既有契约（`PluginContract.HOST_API_VERSION = 1`、`SemVer`、`UiState` 三态），本单元不新增跨模块接口。

## 5. 失败语义与边界

- 坏数据 / 非法版本 / 路径穿越 / 签名不符一律 fail-closed 拒绝并给人话错误，不猜测、不静默降级。
- 远端数据统一走 `UiState`（Loading / Error / Data），加载中禁止展示假数据。
