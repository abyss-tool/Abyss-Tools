## 4. 契约与接口

| 术语 | 定义 |
| --- | --- |
| 大内置化 | v0.8.0 把六个重型插件能力以真实功能页并入主壳 |
| 引擎级插件 | 自带完整引擎（Alpine+PRoot / ClamAV 级特征库 / QEMU），独立 APK + 独立 CI + 独立补丁通道 |
| fail-closed | 校验缺失或失败即拒绝，绝不猜测、绝不静默当作成功 |
| 诚实边界 | 文档中明确声明平台限制（如无 Root 不改 ro.product.*） |

## 5. 失败语义与边界

- 坏数据 / 非法版本 / 路径穿越 / 签名不符一律 fail-closed 拒绝并给人话错误，不猜测、不静默降级。
- 远端数据统一走 `UiState`（Loading / Error / Data），加载中禁止展示假数据。
