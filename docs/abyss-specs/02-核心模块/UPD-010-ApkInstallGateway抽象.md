## 1. 目标与范围

core:update 侧定义的安装网关接口，Android 实现（PackageInstaller）由 :app 注入，保持 core 纯 JVM。

## 2. 现状锚点（克隆研究实测）

- `Abyss-Tools/core/update/src/main/kotlin/com/abyss/tools/core/update/ApkInstallGateway.kt`
- `Abyss-Tools/app/src/main/kotlin/com/abyss/tools/install/PackageInstallerApkGateway.kt`

> 研究口径：2026-11-21 对 `github.com/abyss-tool` 组织下 19 个公开仓库（主仓 / 发布仓 / 插件中心 / 13 归档插件仓 / 3 引擎级插件仓）全量拉取，共 511 个文件；主仓 296 个文件、约 22 个 feature 模块。

## 3. 功能需求

| 编号 | 需求描述（原子、可验证） |
|---|---|
| FR-001 | 接口不得引用 Android 类型。 |
| FR-002 | 实现需处理 STATUS_PENDING_USER_ACTION 确认页转发。 |
| FR-003 | 结果广播等待需有超时与 abandon 清理。 |
| FR-004 | Android 13+ 显式 RECEIVER_NOT_EXPORTED。 |

> 纪律：每条 FR 必须至少被一条 AC 或一个自动化用例覆盖；下表 AC 为关键验收条件，完整覆盖关系由 `QA-008 需求追溯矩阵` 与 spec-lint 登记校验。需求变更需同步更新本文件与对应的测试夹具（`src/test/resources` 为通道契约镜像）。

## 4. 契约与接口

沿用宿主既有契约（`PluginContract.HOST_API_VERSION = 1`、`SemVer`、`UiState` 三态），本单元不新增跨模块接口。

## 5. 失败语义与边界

- 坏数据 / 非法版本 / 路径穿越 / 签名不符一律 fail-closed 拒绝并给人话错误，不猜测、不静默降级。
- 远端数据统一走 `UiState`（Loading / Error / Data），加载中禁止展示假数据。

## 6. 验收标准
