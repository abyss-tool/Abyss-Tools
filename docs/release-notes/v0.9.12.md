## ✨ 新功能

- **FEAT-034 底栏四 tab · 插件独立入口**：底部玻璃导航栏 3→4 tab（仪表盘 / 功能 / 插件 / 设置）——插件中心升为顶层 tab（无返回箭头、标题与 tab 文案一致、底栏第 3 格高亮），旋转 / 进程重建后 tab 恢复；功能页插件分类 / 门面卡 / 插件中心工具行整体移除，分类统计 12→11 数据驱动；仪表盘插件入口统一切到「插件」tab，全 app 单一插件中心深度；`selectTab` 非法索引 fail-closed 直接 return（替代旧 `else -> Settings` 猜测）；新手引导文案同步「四个 tab / 插件（独立 tab）」。
