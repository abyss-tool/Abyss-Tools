# Abyss v0.9.16 更新说明

**发布日期**：2026-11-22  
**版本代号**：observable-update  
**里程碑**：M1 信任与透明（收尾批次）

## 新增

- **N-UPD-003 · 更新链可观测性**
  - 新增 `UpdateEvent` / `UpdateTracer`：覆盖从「检查更新」到「安装完成/失败」全链路 15 个结构化事件点，记录镜像源、阶段耗时、下载字节、重试次数、HTTP 状态码、Range 支持与失败详情
  - 新增 `UpdateSessionSummary` 会话汇总，失败时自动聚合：是否成功、命中镜像、总耗时、总字节、重试次数、失败原因
  - 重构 `UpdateFailureClassifier`：统一枚举 **25+ 失败原因**，每个原因自带人话文案、是否可自行恢复标志与分类标签（网络 / 安全 / 存储 / 安装 / 解析 / 补丁 / 未知）；支持从 Throwable 与 HTTP status 双通道分类
  - 新增设置页 `UpdateFailureSheet` 底部抽屉：更新失败时展示分类图标、人话原因、可恢复性建议、本次会话统计（镜像/重试/耗时/大小/事件数）和诊断ID，附「复制诊断ID」按钮
  - 失败事件通过 `DiagnosticsLog`（UPDATE_CHECK kind）以 WARN 级别落盘

- **N-ENG-009 · 归档仓历史清单漂移治理**
  - 新增 `ArchiveDriftGuard`：在解析 version.json 前强制校验 `schema ∈ {abyss-version-v1, abyss-version-v2}`，越界 fail-closed
  - 必填字段（`versionName` / `versionCode` / `download.url`）缺失即拒绝
  - `download.sha256` 若存在必须为 64 字符十六进制
  - v2 清单 `patch` 必须为 object
  - 漂移时抛 `ManifestDriftException` 并记录诊断日志，防止老版本客户端在归档仓被覆写后静默拉到不兼容清单
