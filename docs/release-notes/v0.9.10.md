# v0.9.10 — 插件权限透明化面板（N-EXP-006）

> M1 里程碑 · 规格落地 ｜ 2026-11-21

## ✨ 新增

- **插件权限透明化面板**（N-EXP-006，P1 / M1）：插件详情页「权限需求」卡重构
  - **FR-001 人话映射**：`permissions: List<String>` 旧字段的常见 Android 权限 ID（INTERNET / SYSTEM_ALERT_WINDOW / WRITE_EXTERNAL_STORAGE 等）与插件域权限 ID（shizuku_shell / root / overlay / cloud_hash_lookup 等）统一映射为人话标签 + 风险等级 + 详细说明，不再直接展示原始权限字符串。
  - **FR-002 Shizuku 双态标注**：独立 APK 插件的 per-app Shizuku 授权声明（`shizuku.ownAuth=true`）与宿主进程内授权分别标注，`reason` 字段全文展示；审阅对话框内单独着色区块突出说明。
  - **FR-003 外传分组置顶**：涉及第三方数据外传的权限（如 VirusTotal 云查毒）按 `PermissionGroup.NETWORK_EXTERNAL` 分组置顶展示，以 error 色容器高亮，并单独标注「⚠ 会上传数据」、数据类别、接收方；本组织通道网络访问（`NETWORK_INTERNAL`）与第三方外传明确区分。
  - **FR-004 安装前显式审阅**：「安装插件（数据框架）」与「安装插件（APK）」按钮点击后不再直接启动安装管线，而是弹出权限审阅对话框；用户必须勾选「我已逐条阅读并接受上述权限与风险」复选框，「确认安装」按钮才会启用，杜绝一键静默同意。失败后的「重试」按钮直接走安装管线不重复审阅。
- 新增 `PermissionAuditCard` / `PermissionReviewDialog` / `PermissionGroupBlock` / `PermissionItemRow` 组件；新增 `legacyPermissionFromId` / `resolvePermissionsForDisplay` 工具函数；`DataInstallUi` / `InstallFlowUi` 增加 `onRetry` 参数分离首次安装与重试回调。
