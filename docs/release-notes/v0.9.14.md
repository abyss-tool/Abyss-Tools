# v0.9.14 发布要点

## ✨ 新功能

- **FEAT-035 设置页分区重构**：设置从单页六区平铺改为分区导航 —— 主页四张入口卡（**权限 / 界面 / 更新 / 关于**），点击进入对应子页（栈深 2、底栏隐藏、旋转/进程重建原位恢复）；全部既有设置项能力零删减重组（偏好键/开关/滑杆/对话框语义逐字不变）。设计语言参考 Ultra-Guru/Android-Guru-Agent 设置中心（姊妹项目）。
- **FEAT-036 应用图标三选一**：设置 → 界面 → 应用图标 —— 三款像素风「深渊之眼」随选随换：**碧眼**（默认）/ **绯眼** / **隐眼**。activity-alias 互斥启停（PackageManager，桌面即时生效）、昼夜双背景三款共用、重启保持；偏好 fail-closed 回退碧眼；切换前 Snackbar 预期管理（图标刷新可能延迟数秒，部分设备会重启应用）。
- **FEAT-037 深渊agent置顶直达**：插件页顶部新增「深渊agent」卡（姊妹项目 Ultra-Guru/Android-Guru-Agent 独立 APK）—— 发布仓 version.json 固定通道拉取版本清单（fail-closed：缺 download/sha256 拒绝）→ **多镜像下载**（ghfast / ghproxy.net / gh-proxy 前缀 + 直连兜底自动择优回退）→ SHA-256 强校验（不符删缓存拒装）→ 确认对话框（版本/大小/摘要）→ 系统安装器；ABI 变体自动选择（arm64 优先，可手动切 universal）。
