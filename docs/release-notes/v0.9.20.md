## 缺陷热修（BUG-登记册 · 7 轮复查基线）

### B-04 · MirroredTransport 原始字节验签（P0）
- `MirroredTransport` 重写 `getBytes`：逐镜返回网络原文字节，堵死缺省接口实现的 String decode/re-encode 往返（CRLF/BOM/非法 UTF-8 归一化曾整链绕过 N-SEC-001 验签承诺）
- `SignedHttpTransport` 签名文件同步走字节路径；get/download/getBytes 三路链遍历收敛为 `tryEachMirror` 骨架
- 回归：`MirroredTransportTest` 4 例（BOM/CRLF/0xFF 字节保真、全链回退 DIRECT、非 GitHub 直通、端到端验签经镜像装饰器）

### B-08/B-17 · Shell 超时与流放弃语义（P0）
- `ShellResult` 新增 `timedOut` / `streamAbandoned` 字段：看门狗触发（fired + elapsed 双信号）→ `isSuccess` 恒 false（超时 ≠ 成功，定时任务不再误判）
- `CappedFdReader.await()` 放弃流时 truncated 置 true（旧实现返回空文本 + truncated=false = fail-open）
- `StreamGuards` 截断后继续排空剩余流（防子进程管道写阻塞到看门狗强杀）
- 终端 / 脚本实验室 UI 对超时 / 流放弃显示明确系统行；回归 7 例

### B-12/B-13/B-14 · 插件与调度（P1）
- `installDataPlugin` 备份→改名→失败回滚三段原子落盘（EISDIR 注入回归：升级受阻旧 manifest 逐字节完好）
- 调度 Intent 单射 data URI 隔离 PendingIntent（碰撞对 Aa/BB 不再共用覆盖）
- `KitCommands.requireSafeToken` 收敛 core:shell 白名单 + 选项形态（- 开头）拒绝

### B-06/B-18 · 深渊agent 信任链（P0/P1）
- 资产 URL 仓库归属硬校验（解析层 + 下载防御深度双层，跨仓库 URL 零网络请求拒绝）
- `signingCertSha256` 实消费：`InstallExpectation` 扩展指纹字段，Android 网关门禁 2.5 安装前逐字节比对 APK 签名证书
- 无指纹锚点的清单不再提供安装通路（fail-closed）

### B-05 · 发布说明门禁闭合（本版落地）
- 主仓 CI 对 `docs/release-notes/v*.md` 逐文件强制校验（原 latest.md 双跳过消除）；历史 21 份说明统一要点格式
- `publish_release.py` 发布前置 N-ENG-010 门禁（与校验脚本共用同一入口，notes 不合格 → 任何网络写之前拒绝）
- version.json notes 保留逐行结构（旧「；」单行压缩让要点识别恒为 0）
- auto-release 缺省回退改结构化三要点（PR 标题不再直填 notes）

## 风险与边界

- Shell 语义变更：`isSuccess` 在 timedOut 时恒 false —— 依赖「exitCode==0 即成功」的调用方（蓝图定时任务）行为收紧，失败判定更如实
- agent 通道：清单缺 `signingCertSha256` 或资产 URL 越界将整卡 Error（不再降级可用）—— 已核对线上通道清单合规
- 主仓插件中心：Hub `plugins.json.minisig` 已落库（B-02），病毒插件补丁通道签名已补（B-03）
