# v0.4.0 —— 内置七工具真实功能页 + 插件链路收口 + Android 15/16 适配

- 应用管理器真实功能页：全量列表（搜索 / 排序 / 用户·系统过滤）、冻结与解冻（pm disable-user / enable）、隐藏与显示（pm hide / unhide，含隐藏态对账）、强制停止（am force-stop，二次确认）、提取安装包（导出 + 系统分享）、卸载引导（用户应用直达系统卸载页）
- Shizuku 工具箱真实功能页：appops 查改面板（预设 + 自定义 op，ALLOW / DENY / DEFAULT 三态设置）、系统设置面板（global / system / secure 三表读写，危险写入二次确认）、dumpsys 白名单摘要（九条预设，64KB 截断保护）、指令历史（50 条本地持久化，点击回放预填）
- 任务蓝图真实功能页：JSON 步骤链引擎（SHELL / TOAST / DELAY 三型步骤，成功判定 successProbe、超时控制、continueOnFailure、{prev_output} 变量替换）+ 蓝图库（五个内置蓝图：电池恢复 / 飞行模式开关 / 网络开关）+ 全屏 JSON 编辑器（解析校验 + 错误人话）+ 执行历史（最近 20 条）
- 自动化编排真实功能页：精确闹钟定时执行蓝图（setExactAndAllowWhileIdle，SecurityException 自动降级）、开机自动重排调度（BootReceiver，闹钟不随重启丢失）、调度清单管理（开启 / 取消 / 到期执行落史）
- 灵动岛悬浮球真实功能页：悬浮窗授权引导（Settings.canDrawOverlays）+ 前台服务保活 + WindowManager overlay 悬浮球（拖拽实时跟随、松手吸边、点击展开）+ 快捷面板（真实电量读数 / 充电状态 / 时钟 / 打开深渊工具）+ 外观设置（大小 / 透明度 / 四色主题）+ 页内面板预览
- 动态壁纸真实功能页：液态玻璃同源光斑引擎（深渊青 / 余烬橙 / 绯红 / 苔原绿四主题，双层柔光 + 缓慢漂移 + 主页滑动视差，30fps 不可见自动暂停）+ 实时预览 + 速度调节 + 一键设为（ACTION_CHANGE_LIVE_WALLPAPER，旧 ROM 降级选择器）
- 二维码工坊真实功能页：ZXing 生成（四级纠错 / 尺寸 / 六组深渊色板 / Compose Canvas 直绘实时预览）+ 相册解析（Photo Picker，QR + Code128 / EAN13 / UPC-A / ITF 多格式）+ 保存 PNG（API 29+ MediaStore / 26-28 公共目录双路径）+ 分享 + 历史（30 条）
- 插件 APK 安装一条龙收口：installApkPlugin（下载 → SHA-256 校验 → 系统安装器 → 版本账本同步）—— 修复装完 APK 后本机登记停留在旧版本、补丁通道 from 比对算错的缺口；安装过程四阶段反馈（下载 / 校验 / 安装 / 登记同步）
- 插件中心一键检查更新：并发拉取全部已装插件的补丁通道，「N 个可更新」摘要 + 可更新徽章，直达详情页应用补丁
- 插件 APK 本体卸载引导：从缓存 APK 解析包名直达系统卸载确认页，缓存已清时降级系统应用设置
- Android 15/16 适配矩阵（docs/ANDROID_COMPAT.md）：16KB page size 声明（主壳零 native 自动合规 + useLegacyPackaging=false 前向兼容）、广播注册 RECEIVER_NOT_EXPORTED 加固（Android 13+ 显式声明，安全审计零告警）、edge-to-edge / FGS / 精确闹钟 / scoped storage 等逐项立场文档化
- 版本升至 0.4.0 (5)；模块地图新增 feature:{appmgr, shizukukit, qrcraft, blueprint, island, wallpaper}
