## N-ENG-001 · 本地可复现门禁（零「CI 绿本地红」）

- 新增 `tools/local_gate.sh`：一条命令复现与 GitHub Actions CI 完全相同的门禁（assembleDebug + assembleRelease + test + validate_manifests + spec_lint + ui_text_budget + 发布说明逐文件门禁）
- 三模式：`full`（全量）/ `--jvm`（仅 Python 门禁，无需 JDK / Android SDK）/ `--gradle`（仅构建与单测）；工具链版本钉死于脚本头（JDK 17 / Gradle 8.14 wrapper / compileSdk 36）
- CI `manifests` 任务收敛为调用同一脚本 `--jvm` 模式 —— 两侧共用单一入口，永不漂移（FR-003）
- 签名材料缺失时 release 降级未签名产物并显著提示（FR-004，与 CI fork PR 同语义）；README 构建章节重写，AGENTS.md 纪律同步（合并判决仍以 Actions 为准）
