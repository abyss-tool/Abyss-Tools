## 概述

本版本完成 M1 里程碑**规格状态同步**：确认应用构建器插件（abyss-plugin-app-builder）与 Linux 运行时插件（abyss-plugin-linux）的三批 P0 需求（脚手架 / Alpine+PRoot 底座 / Shizuku 独立授权）已在独立插件仓按**瘦客户端架构**落地，主仓同步更新规格状态为「已实现」。

## 架构定稿（ADR-100 D-3 · 瘦客户端切片边界）

经 2026-11-22 架构评审（ADR-100 D-3 / ARC-103），插件生态最终形态定稿：

- **abyss-plugin-linux**（新底座仓）：承载 Alpine + PRoot + QEMU 双执行域 + ptrace 探测降级链 + Shizuku per-app 授权（**全生态唯一授权点**，授权次数=1）
  - 模块：probe/（5s 超时只读探测）、domain-proot/（Alpine mini rootfs 约 4MB 无 Termux 依赖）、domain-qemu/（完整系统域预留）、shizuku/（ownAuth 检测+shell 拉起）、session/（会话+持久化状态）、runtime-api/（跨插件 AIDL 契约）
  - CI：assembleDebug/assembleRelease + pure-JVM 单测全绿
- **abyss-plugin-app-builder**（瘦客户端）：**零引擎、零授权、零资产管线**，只承担
  - 依赖握手与 SessionGrant 消费（runtime-client/HandshakeGuide：七步握手 + 六类失败引导）
  - 静态项目预检（precheck/ProjectShape：三路径推荐 + 硬性标注 + 二次确认）
  - 构建编排与产物闭环（M2 起逐路径落地）
  - CI：Plugin CI run #14 全绿（assemble + test）
- **跨插件中介**：宿主 PluginBroker（HOST_API v2）统一做依赖解析、能力发现与 SessionGrant 签发；插件之间永不直连（ARC-103 N-2）
