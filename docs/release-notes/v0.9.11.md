# Abyss v0.9.11 更新说明

**发布日期**：2026-11-22  
**版本代号**：observable-update  
**里程碑**：M1 信任与透明（收尾批次）

## 新增

- **N-UPD-003 · 更新链可观测性**
  - 新增 `UpdateEvent` / `UpdateTracer`：覆盖从「检查更新」到「安装完成/失败」全链路 20+ 个结构化事件点，记录镜像源、阶段耗时、下载字节、重试次数、HTTP 状态码、Range 支持与失败详情
  - 新增 `UpdateSessionSummary` 会话汇总，失败时自动聚合：是否成功、命中镜像、总耗时、总字节、重试次数、失败原因
  - 重构 `UpdateFailureClassifier`：统一枚举 **25+ 失败原因**，每个原因自带人话文案、是否可自行恢复标志与分类标签（网络 / 安全 / 存储 / 安装 / 解析 / 补丁 / 未知）
  - 新增设置页 `UpdateFailureSheet` 底部抽屉：更新失败时展示原因分类、具体建议、本次会话统计（镜像/耗时/重试/大小/事件数）和诊断ID，附「复制诊断ID」按钮方便反馈
  - 失败事件同步写入 `DiagnosticsLog` 落盘 + `DiagnosticExporter` 内存统计，诊断中心可以按 update_app / update_plugin / update_patch 分类查看

- **N-ENG-009 · 归档仓历史清单漂移治理**
  - 新增 `ArchiveDriftGuard`：解析 index.json 前强制校验 `protocol_version ∈ [1,2]`，越界 fail-closed
  - 必填字段（`versionName` / `versionCode` / `url` / `sha256`）缺失即拒绝
  - `sha256` 必须为 64 位十六进制字符
  - 检测到漂移抛 `ManifestDriftException` 并记录诊断日志，防止老版本客户端在归档仓被覆写后静默拉到不兼容清单

## 修复

- `UpdateFailureClassifier` 错误地把 JSON 解析失败全部归为 UNKNOWN；新分类器细化为 INDEX_PARSE_FAILED / MANIFEST_DRIFT / HTTP_4XX / HTTP_5XX / REDIRECT_TO_UNTRUSTED_HOST 等具体原因
- 失败页之前只显示 toast，无法看到具体原因与建议；现在提供完整详情抽屉
