# v0.9.18 · N-VIR-001/002/006 病毒拦截信任判定管线与误杀防护

> 发布日期：2026-11-27 · 里程碑：**M1** · versionCode 41

## 新增能力

### N-VIR-002 · 信任判定管线（纯 JVM，P0）
- 新增 `virus` 核心包：`ScanSubject`/`Verdict`（CLEAN/SUSPICIOUS/MALICIOUS/UNKNOWN）/`VerdictReason`/`VerdictReport`
- **4 个内置 checker 按优先级短路执行**：allowlist(5) → blacklist(10) → local-rules(20) → cloud(30)
- MALICIOUS 命中立即短路；白名单命中直接 CLEAN 但理由链仍留痕（可审计）
- **无任何信号时返回 UNKNOWN 而非 CLEAN**（严格 fail-closed，FR-001 不静默放行）
- checker 异常容错：单个 checker 抛异常时捕获为 UNKNOWN 理由，不影响其他 checker
- 单测覆盖四种 verdict + 云不可达降级 + checker 异常容错

### N-VIR-001 · 安装事件拦截骨架（P0）
- `InstallMonitorMode`：`SHIZUKU_SESSION`（可拦截）/`BROADCAST_ONLY`（仅提示）/`POLLING_DUMPSYS`（ROM 兜底）/`DISABLED` 四档
- `InstallEventBus`：集中事件总线，幂等注册（FR-004 开机恢复不重复）、线程安全、监听器异常隔离
- Android 侧 Shizuku Session / BroadcastReceiver / dumpsys 轮询实现通过总线挂载（后续里程碑接入）

### N-VIR-006 · 误杀防护与审计日志（P0）
- **默认策略硬约束 `autoUninstallMalicious=false`**：MALICIOUS 判定只拦截不自动卸载（FR-001）
- `VirusAuditLog`：本地审计日志，512KB 自动轮转保留最近 2 份
  - 每次扫描/拦截/用户放行/加白/撤销处置都留痕
  - 导出时默认 sha256 脱敏（前8+...+后8），含"未随云查询外传"声明
  - 不写文件路径、不写 token、不写隐私（FR-005 零外传）
- `VirusDispositionExecutor`：处置决策 + 误报申诉入口（一键加白名单并可撤销处置），全部操作写审计
- `DiagnosticsLog.Kind` 新增 `VIRUS_SCAN`，病毒事件接入诊断中心

## 风险与边界

- 本版本仅交付**纯 JVM 判定核心 + 事件总线骨架 + 审计/白名单**，Android 侧真正的 Shizuku install-session 监听、BroadcastReceiver 注册、通知前台服务保活等集成工作在下一批 N-VIR-001 后续项和 UI 面板（N-VIR-005）中完成
- `CloudUnavailableChecker` 为云查询占位实现（始终返回不可达 UNKNOWN），真正的 VirusTotal 配额调度在 N-VIR-004 落地
- `LocalRuleChecker` 仅内置三条基础启发式规则（空包名/未签名/超大无包名），ClamAV 级签名库在 N-VIR-003 落地
- 纯 JVM 单测 3 个测试类、18 条用例全部通过
