# v0.9.18 发布说明 · 病毒拦截核心骨架（M1）

> 版本：v0.9.18 (versionCode 41)｜渠道：stable｜发布日期：2026-11-27

## 摘要

本版本交付 M1 里程碑 P0 病毒拦截核心骨架：纯 JVM 可测的信任判定管线、误杀防护与审计日志、安装事件拦截状态机，为病毒拦截插件（HUB-012）提供可单测、可审计、默认安全的底座。

## 新增

- **N-VIR-002 信任判定管线（纯 JVM）**：
  - 判定结果四态 `CLEAN/SUSPICIOUS/MALICIOUS/UNKNOWN`，`UNKNOWN` 不得当作 CLEAN
  - 规则优先级与短路策略可配置：哈希黑名单 → 发布者签名白名单 → 本地启发式 → 云查询
  - 云查询不可用时自动降级 UNKNOWN，不静默放行
  - 每条判定保留可审计理由链（命中规则/签名/云结果）
- **N-VIR-006 误杀防护与审计日志（纯 JVM）**：
  - 默认策略下 **任何 MALICIOUS 判定都不自动卸载**，必须用户确认
  - 审计日志记录时间/包名/版本/哈希/verdict/理由链/操作者/结果，仅写本地沙箱，**零外传**
  - 白名单双轨（sha256 + 包名双重键），支持用户一键标记误报并撤销处置
  - 内存环形缓冲 + 可选磁盘滚动文件（512KB 轮转，保留 2 份）
- **N-VIR-001 安装事件拦截骨架（状态机，纯 JVM）**：
  - 监听能力五档：`SESSION_BLOCK/SESSION_OBSERVE/BROADCAST_ONLY/POLLING_FALLBACK/DISABLED`
  - Shizuku 可用时可拦截；不可用时自动降级为仅提示并明确降级口径
  - ROM 会话广播不支持时主动降级到 dumpsys 轮询
  - 开机恢复监听幂等（重复 start 不重复注册）

## 测试

- 新增 `VerdictPipelineTest`：11 个用例覆盖四种 verdict、黑名单短路、可信签名、云高/低命中、云不可达降级、非法哈希、规则异常 fail-closed
- 新增 `FalsePositiveGuardTest`：8 个用例覆盖默认不自动卸载、自动阻断策略下 MALICIOUS 仍需确认、误报白名单恢复（AC-001）、审计字段完整性、环形缓冲裁剪、白名单磁盘持久化
- 新增 `InstallEventGuardTest`：10 个用例覆盖有/无 Shizuku 两档、权限拒绝、ROM 降级、用户禁用、开机幂等、事件去重、启停状态、完整会话模拟（AC-001）

## 安全

- 默认 fail-closed：规则执行异常/云不可达/信息不足一律降级 UNKNOWN，不静默放行
- 审计日志零外传：仅写本地沙箱，不含任何 token/密钥/路径隐私字段
- 白名单双重键：按 sha256 + 包名双重复合，防止跨包名绕过
